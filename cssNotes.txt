Selectors
=========
Class Selectors (.) override element selectors

ids should exits once, ids should be unique
classes and element selectors are more common, rarely should id's be used 

mostly used to link form input back to a label element
even JS might have id uses 

grouping selectors
------------------
all h1 and h2 is selected
h1, h2{
    color:red
}

h2 inside of h1 (descendants)
h1  h2{
    color:red
}

universal selector (*)

cascade, works top to bottom
the last rule is applied, sepcificity can override this


Inheritance
all elements inherit properties from the parent element
html is parent to all elements


universal selector is NOT Inheritance, it jus applies it all the elements

form elements don't inherit font settings

!important,overrides everything else, NUCLEAR option

Units and Sizes
===============

Unit | Name                 | Equivalent
-----|----------------------|-----------------------------
cm   | Centimeters          | 1cm = 37.8px = 25.2/64in
mm   | Millimeters          | 1mm = 1/10cm
Q    | Quarter-millimeters  | 1Q = 1/40cm
in   | Inches               | 1in = 2.54cm = 96px
pc   | Picas                | 1pc = 1/6in
pt   | Points               | 1pt = 1/72in
px   | Pixels               | 1px = 1/96in

absolute units
Pixels - px

using absiolute font size, takes away control from users to change the font size

Relative units 
% - percentages

rem - font size of the root element
    root is defined by the browser
    default - 1rem (root em) 

em - root of the root
vw- 1% of viewports width ; 50 vw=50% of width
vh- 1% of viewports height

CSS Reset
*{
    margin:0;
    padding:0;
    box-sizing: border-box
}

Body is not the full height of the page, it only grows with the content
but we would want the body's height to be the full length of the vierwport's height,
regardless of the content, set 

body{
    min-height:100vh
}

The main difference between em and rem in CSS is their scaling base:

- em is relative to the parent element's font size, 
- rem is relative to the root (<html>) element's font size.

Display
-------
block
    - have 100% width (of what is avaiable to them (parent container)) 
    - they stack on top of each other
    - create a new line

inline
    - only take up width of the content 
    - do not stack on top of each other
    - do not create a new line
    - no margin nad height can be applied
    - padding can be applied

inline-block
    - hybrid of the 2 
    - keep the content inline, but also apply margin, padding, height etc
      that only block level elements can have
    - style links as buttons, turning a list into a row

none:
    - removes element from the document flow
    
margin-inline: applies to left and right
